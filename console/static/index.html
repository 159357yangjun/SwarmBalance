群智优衡 · 推荐操作流程

1. 先选“场景”，再选“算法”普通使用可从“场景库”或“答辩演示场景”开始；算法切换后点击“重置”让调度器从同一 Seed 重新开始。
2. 用播放 / 单步观察真实调度2D/3D 地图、任务链、机巢队列和事件日志都来自同一仿真会话。需要看清一次重规划时，先暂停再点“单步”。
3. 运行中制造变化可新增紧急任务、调整待调度任务 SLA、要求无人机补能、制造无人机故障或关闭机巢，随后让当前算法在现有状态上继续决策。
4. “快照”和“场景库”不要混用快照恢复动态节点；场景库恢复可分享的初始配置。结构性场景编辑会重建环境，因此重要动态节点请先明确是否需要保留。
5. 结项数据去“实验”页交互式仿真负责展示系统能力；一键实验负责重复评测与敏感性分析。两者共用同一环境和调度算法。
