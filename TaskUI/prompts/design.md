# TaskUI 设计启动提示词

你在此项目中按 `TaskUI/AGENTS.md` 执行 G0 和 G1。**不要先写前端代码。**

我会提供软件目标、现有功能、用户角色、平台和技术栈；若有信息不足，请列出影响布局的关键假设并提出最多 3 个核心问题。按顺序输出：

1. 核心业务对象与典型工作场景。
2. 按频率/范围/风险分类的任务-操作映射表。
3. 选择的布局模式及其理由（可组合）。
4. 工作空间低保真线框图（文本/Markdown 均可），注明常驻和按需出现的区域。
5. 每个关键操作的入口、快捷方式、反馈、失败恢复。
6. `project.taskui.json` 草案和设计证据文件。
7. 可用性风险清单，包括何处可能造成功能堆积或频繁跳转。

运行 `TaskUI/tools/taskui_check.py`（如果当前有代码执行能力），提交诊断。仅在 G1 完成、并获得方案确认后进入 G2。
