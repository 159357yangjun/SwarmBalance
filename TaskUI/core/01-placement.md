# Core 01 — 功能入口与决策矩阵

## 先问六个问题

1. **频率**：日常多次还是偶尔？
2. **范围**：global / workspace / object？
3. **上下文**：操作需要选中什么、查看什么？
4. **关联**：是否与其他操作连续完成？
5. **风险**：误触发的代价与恢复手段？
6. **空间**：常驻是否值得挤占主工作区？

## 候选入口选择

| 典型情境 | 首选入口 | 备选 |
| --- | --- | --- |
| 高频全局动作 | 顶层菜单/紧凑工具栏 | 快捷键、命令面板 |
| 高频对象动作 | 对象附近的快捷操作/上下文菜单 | 快捷键、详情面板 |
| 批量处理 | 选择集合后出现批量工具栏 | 右键菜单 |
| 低频设置 | 设置页或深层菜单 | 搜索设置 |
| 属性调节 | 属性面板/就地编辑 | 对话框（复杂操作时） |
| 不可逆高风险动作 | 清楚标识的操作入口 + 确认/安全恢复 | 延迟执行/软删除 |
| 长流程操作 | 向导/专门工作区 | 保存草稿及进度恢复 |

## 禁止机械化的数字规则

不要规定“所有高频动作最多 2 次点击”。真正的耗时还包括找入口、阅读、输入、确认与恢复。步数预算应针对任务、角色和环境独立设定，并通过走查验证。
