# Adapter：Windows/macOS/Linux 桌面（Tauri / Electron / Native）

- 支持传统菜单、键盘快捷键、右键菜单、文件拖放、窗口尺寸记忆与多窗口行为（按产品需要）。
- 遵循目标操作系统的菜单、标题栏、系统快捷键与文件选择器惯例。
- 工作区面板可考虑可调整宽度、关闭和恢复布局；稳定性优先。
- 关键任务检查窄窗口、全屏、125%/150% DPI 等缩放环境。
- 涉及本地文件的操作要定义覆盖、权限错误、文件锁定、失败恢复。
- 自动化可用 Playwright（Electron/WebView 在支持条件下）或平台 UI 自动化，但必须真的运行应用。
