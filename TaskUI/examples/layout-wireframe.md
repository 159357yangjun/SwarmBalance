# 资源管理工作区线框（示例，并非真实实现截图）

```text
┌─────────────────────────────────────────────────────────────────┐
│ 文件 | 编辑 | 查看       [搜索/筛选 Ctrl+F]           状态       │
├───────────────┬─────────────────────────────────────────────────┤
│ 文件夹树      │ 文件列表（主工作区）                           │
│ - 最近使用    │ 文件名      修改时间      大小                 │
│ - 我的资源    │ image1.png    ...          ...                 │
│ - 回收站      │ image2.png    ...          ...                 │
│               │                                                 │
│ 可折叠        │ 右键：重命名 / 删除；F2 快速重命名              │
├───────────────┴─────────────────────────────────────────────────┤
│ 已选中 1 项                            筛选状态 / 任务状态     │
└─────────────────────────────────────────────────────────────────┘
```

资源预览默认隐藏，选中后由用户按需打开。列表至少保持声明的宽度目标；须在目标窗口尺寸实际测量。这里不是布局实现证明。
