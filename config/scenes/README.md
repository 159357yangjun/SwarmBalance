# 场景库目录

Web 控制台的“场景库”会把用户保存的可复现场景写入本目录，每个文件都是独立 JSON。

- 场景文件保存：`simulation.json` 全量配置、算法、Seed，以及可选的 `backend_si/config.yaml`；
- 场景库用于“从同一初始配置重新开始”；
- “运行态快照”用于当前服务进程内恢复某一动态仿真节点，两者不要混淆；
- 导入场景会先做格式和配置一致性校验，不会直接覆盖当前仿真；只有点击“应用并重建”才会切换；
- 建议不要把个人临时场景提交到公共仓库，可按需要在 `.gitignore` 中忽略 `config/scenes/scene_*.json`。
