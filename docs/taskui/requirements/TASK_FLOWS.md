# TASK_FLOWS｜用户任务路径、断点与验证剧本

> 基线 `master@2ab60c69a806a22d7ba20353dee0571752a0e8e5`。本文件记录由界面模板和 API 还原的**可推导路径**，不是实际点击录像。  
> 记号：**I** 静态可证现有步骤；**O** 已在代码结构中确认的跨视图/保存语义；**H** 需要实测的效率或认知假设。点击数量、成功率、耗时**尚未测量**。

## F01｜准备与启动（T01/T02/T17）

**当前路径（I）**：打开 `/` → 预热完成、加载 `/api/snapshot` 和 `/api/map` → 顶栏选算法和 Seed → 点“重置”（`/api/reset`）→ 播放/单步（`/api/step`）→ 查看步数、时间、指标。  
**观察事实（O）**：切算法触发 `onAlgorithmChange() {}` 空方法；只有重置真正将新算法应用，状态栏存在“待生效”提示（`index.html:603-614,1966,1157-1165`）。  
**待实测（H）**：使用者是否清楚“待生效”并会主动重置；播放→暂停→切换工作区期间是否错过状态。  
**G1 需求**：运行控制的当前状态与待生效状态在全工作区保持可辨认；不要默认为切换算法立即生效。

## F02｜编辑场景布局（T12/T13）

**当前路径（I）**：顶栏“场景编辑” → 读取配置 → 编辑机巢/圆形禁飞区 → 必要时关闭弹窗、进入 2D 地图取点 → 返回弹窗 → 保存并重建（`/api/scene-layout`）→ 查看更新后地图。普通“配置”另以 `/api/config`、`/api/scheduler-config` 写入再调用 `/api/rebuild`。  
**观察事实（O）**：地图取点是 modal→地图→modal 模式；非 random 数据源禁止保存；配置保存涉及独立顺序接口（`index.html:1794-1849,2577-2608`；`server.py:667-805`）。  
**待实测（H）**：多次拖动/新增对象是否造成上下文切换；两个配置请求中第二次失败时用户能否识别部分写入。  
**G1 需求**：结构性编辑应与运行干预显式分区，提交前显示“重建/当前运行态影响”，不承诺尚不存在的原子事务。

## F03｜场景库复用（T14）

**当前路径（I）**：顶栏“场景库” → 命名并选择是否含算法超参 → 保存；列表→应用并重建 / 导出 JSON / 删除；亦可导入 JSON（`/api/scene-library*`）。  
**观察事实（O）**：导入只加入库不自动覆盖仿真，应用会恢复场景内算法/Seed并重建，演示模式期间应用被拒绝（`server.py:562-660`）。  
**待实测（H）**：用户是否把导入与应用混淆，或以为保存场景包含当前运行状态。  
**G1 需求**：每个动作明确“库内操作”与“作用当前仿真”的结果。

## F04｜运行中插单、候选解释与重调度（T05/T06/T07/T09）

**当前路径（I）**：顶栏“＋新任务”→选预设/属性与位置模式→可从 2D 地图选择起终点→提交至当前仿真→进入控制层/定位任务→待调度任务详情可改优先级/SLA/重量/类别→刷新候选解释→单步/播放观察任务链与事件。  
**观察事实（O）**：`submitTask` 会把 `tab` 切为 dispatch，但地图只有在 `showMap` 时可见；`goPage` 的控制层切换明确设 `showMap=false`（`index.html:2523-2545,2663-2687`）。  
**待实测（H）**：是否要反复“控制层↔实现层”才能把任务候选与地图位置关联；实体选择的详情在跨页之后是否容易发现。  
**G1 需求**：保留对象 ID、选中状态和任务上下文；支持诊断任务时连续获取地图定位、详情和事件（不要求当前已同屏）。

## F05｜故障/机巢关闭及恢复（T08/T10/T11）

**当前路径（I）**：控制层暂停自动订单流（可选）→随机故障/选具体对象故障→显示停飞/关闭状态与事件→单步触发调度→检查待调度池/机巢队列→恢复对象/全部资源。  
**观察事实（O）**：事件注入停止 Web 自动播放，不重置底层世界；“恢复全部”依次请求每个对象并非后端单事务（`index.html:1740-1791`）。  
**待实测（H）**：操作者能否区分“暂停自动订单流”和“暂停仿真”；多资源恢复中途失败能否识别已恢复对象。  
**G1 需求**：分离这两种“暂停”；异常级反馈保留对象 ID、状态变化、恢复入口。

## F06｜运行态快照回放（T16）

**当前路径（I）**：数据处理展示层→输入检查点名→保存→回合继续→选检查点“恢复”→重现快照后的运行，或删除。  
**观察事实（O）**：检查点仅进程内最多 5 个，同名覆盖，环境代不匹配拒绝恢复（`sim_session.py:395-553`）；当前 UI 列出恢复按钮，但尚需运行验证“不兼容时的可用性”提示是否充分。  
**待实测（H）**：场景库与快照名字相似是否误选、环境变更后的恢复失败是否被理解。  
**G1 需求**：可恢复/不兼容与作用域醒目显示；恢复操作必须明确会替换当前动态状态。

## F07｜观测任务生命周期、飞行轨迹与异常（T03/T04/T07/T09）

**当前路径（I）**：实现层点击无人机/任务/机巢→浮动检查器读载重、电池、任务链、泊位队列/候选匹配→点击任务链中任务；也可控制层从待调度列表、任务链或事件选中对象。  
**观察事实（O）**：地图的 inspector 是覆盖层，CSS `width:min(370px,46%)`；控制层为独立 view；事件只取最新 30 条/坞内 12 条（`index.html:675-783,976-983,1089-1152`）。  
**待实测（H）**：关键航段是否被 inspector 遮挡、同一时间点事件与轨迹能否快速完成解释、异常被截断后是否妨碍分析。  
**G1 需求**：地图为主观察面；对象详情可关联事件和任务链，允许查看时不丢地图选中对象。

## F08｜指标与能耗分析（T17）

**当前路径（I）**：数据处理展示层→运行态势→完成率/超时率/资源/能耗统计与趋势；算法/控制层右侧坞亦展示精简读数。  
**观察事实（O）**：主指标页与地图互斥（`showMap`）；能耗在数据层/实时坞按 kWh 显示，对比 CSV 指标按 Wh 标单位（`index.html:1137-1140,2613-2622`）。  
**待实测（H）**：操作者是否能辨认实时运行指标与离线算法对比结果的数据来源及时间范围。  
**G1 需求**：分清实时会话与正式实验指标，明确单位、快照时点和数据来源。

## F09｜实验预设、结果对比与证据包（T18/T19/T20/T22）

**当前路径（I）**：算法层→选择实验预设→“一键运行”（`/api/experiments/start`）→查看进度、当前工作和目录→刷新对比（`/api/compare`）→若正式 conclusion 数据可用则下载证据包。  
**观察事实（O）**：`/api/compare` 从指定 CSV 取每算法最后有效行，并通过 `compare_gate` 标出不可比情形；未找到任意历史实验结果选取器（`server.py:814-960`）。  
**待实测（H）**：用户会不会把“最新显示数据”误当成“刚启动的实验”；在不可比提示出现时是否仍错误报告胜者。  
**G1 需求**：结果来源、比较口径、正式/非正式状态先于图表胜者；任意历史批次选择不属于本阶段已确认能力，不纳入必做页面范围。

## 测试观察记录模板（实施 G1 前完成）

每个 F01～F09 实测填写：样本身份情境／设备与分辨率／起始会话状态／任务完成(Y/N)／实际路径（不预置点击数）／耗时（起止事件定义）／误操作及恢复／反馈是否被看见／证据截图或录像链接。不得凭静态源码补填耗时或宣称误操作频率。

## 路径问题优先级（待 G1 评审）

1. **P0-H**：运行中地图/控制层跨视图导致诊断上下文可能中断（静态结构确证、效率影响待实测）。
2. **P0-H**：结构性变更、动态节点恢复、事件注入影响范围不易区分（操作语义确证、误操作率待实测）。
3. **P0-H**：实验图表应持续维持口径门禁和结果来源（既有科研安全约束，禁止退化）。
4. **P1-H**：顶栏同时暴露低频配置和高频运行操作，优先层级待真实任务测量。
5. **P1-H**：地图 inspector 覆盖面积、事件可见数量是否限制诊断待实际分辨率核实。
