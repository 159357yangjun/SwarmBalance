## 非模态功能/按钮

- **仿真**：算法下拉只更改下一次 reset 参数；切换后需重置；播放/暂停、单步、倍率、2D/3D 与状态栏在顶部（601-630, 1899-1966）。
- **控制**：暂停/恢复自动订单流、人工插入任务、随机无人机故障、随机关闭机巢、全部恢复（913-930）；列表按任务/机巢/无人机选择实体（933-974）；事件点击关联实体（976-984）。
- **指标页**：演示预设加载、执行下一幕、恢复演示前配置（811-832）；运行态快照保存/恢复/删除（834-850）；态势、建议、12 KPI、2 个实时图和趋势（852-897）。
- **算法页**：指标下拉、刷新对比（998-1009）；选择实验预设、一键运行、刷新状态、下载结项包（1011-1038）；对比门禁错误/不可比提示（1042-1077）。
- **地图**：2D 点击命中；任务/场景取点；3D Raycaster 选取（2018-2064, 2438-2443）。图例和竖向夸张比例警告（785-795）。
- **空态/错误态**：任务/队列空态、候选为空（698,730,778,941,953,971,982）；reset/step/config/scene/incident/experiment/compare 局部提示；加载层、缺依赖页（588-600,669）。
- **页面 URL**：初次 hash 支持 impl/control/algo/data/spec 及几个别名（3018-3024），没有真实客户端路由文件（S）。
