# MAP-IMPORT-01：选区 → 小块查询 → 缓存 → 可检查地图包

## G0：用户任务与成功标准
用户：SwarmBalance 模拟实验设计者。
任务：在现有 GIS 预览页选择一个可控区域，在线获取其真实 OSM 要素，并复用缓存；不手动下载省级地图、不修改原杨浦仿真。
数据对象：BBox(WGS84)、Overpass WayTile、ImportJob、GeoJSON MapPreviewPackage、QualityReport。
风险：公众 Overpass 服务限流，超大范围滥用，OSM building heights 缺失，关系多边形遗漏，GPS 经纬度误作米制坐标，旧的运行实验发生改变。
成功标准：选区合法性、后台状态、可见真实图层、可重试、缓存命中、数据来源与非正式仿真状态明确、原仿真无修改。

## G1：信息架构与线框图
不新增主导航页，继续使用 `/map-lab` 地图页面。
```
顶栏（返回原控制台 / 返回项目工作台 / OSM 署名）
左栏：①选择区域（按钮 + 经纬度输入 + 面积验证）
      ②准备地图（强制重抓选项 + 发起/取消 + 进度/异常）
      ③检查图层（图层开关/数量 + 质量声明）
主区：按需在线底图 + 可编辑选区 + 已准备真实空间要素
```
默认佛寺镇约 5×5 km；选区变化则清除旧图层，防止把过期地图冒充当前地图。
空态：未准备数据时显示“未准备”，仍能浏览底图；
进行中：显示总块数、完成块数、当前阶段；
失败：可重试并复用已缓存块；
重启：残留进行态明确标记 interrupted；
取消：请求取消，明确当前网络请求不可瞬间中断。
键盘：按钮/输入/开关可 Tab 操作；Esc 中止鼠标选区；经纬度表单支持纯键盘操作。
小屏：地图上置，编辑面板下置。
所有危险写入限于 `data/map/gis/`，不得改变原 World、Scenario、Run 及历史产物。

## G2：实现边界
`console/gis_import.py` 为独立只读源数据准备器：小区域阈值、串行分块、请求退避、磁盘缓存、hash 确认包、job 状态。
`console/map_lab.py` 路由；`console/static/map_lab.html` + `map_lab.js` 展示。
保留原控制台及 `legacy_direct`。只提供 GeoJSON 预览，空间计算前必须另行开展 CRS、reprojection、multipolygon/DEM 和障碍质量验收。
