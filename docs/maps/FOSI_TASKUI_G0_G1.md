# 佛寺镇地图试验区 — TaskUI G0/G1 设计证据

状态：只读地图数据预览，**尚未做浏览器 G3 实测验收**。

## G0 任务与风险
用户为 SwarmBalance 的地图数据准备者和仿真实验研究者。主要任务：同步仓库 → 启动已有服务 → 选择地图入口 → 浏览佛寺镇附近 → 检查真实 OSM 数据就绪状态 → 按需下载/裁剪图层。
对象包括：试验区 bbox、在线底图、本地 GeoJSON 图层、数据清单。不是 Run/Scenario 的运行状态。
风险：地图空白误判没有建筑；GeoJSON 经纬度未经投影误算为米；用户误以为运行的是佛寺镇仿真。
成功条件：入口可找到、在线地图可浏览、无数据态可见、GeoJSON 缺失有明确指引、返回工作台不丢运行状态。

## G1 布局、交互和恢复
模式：object-management（地图/图层对象）+ monitoring-analysis（数据质量状态）；不用卡片堆砌主页。
线框：顶栏左品牌、右返回原控制台/工作台；地图占主工作区；左侧列出状态、图层、下载指令；手机宽度地图上置。
加载、无数据、网络/CDN 失败、单图层失败均有文案；支持图层开关与回到试验区按钮；原工作台和旧控制台各有一个上下文入口。
不会自动运行网络下载/修改配置。下载被 Git 忽略。OSM 署名可见。

## 设计约束及后续验收
本批只改 read-only map endpoints/preview，不改算法、能耗、地图模型、启动协议、Frozen data。
当前未通过真实浏览器走查、地图数据下载后完整性校验及 TaskUI strict manifest 验收；后续需要单独 G3 证据。
