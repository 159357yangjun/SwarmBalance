# 世界逻辑规格书（World Model Spec）

> 目的：把仿真内核里"实际已经在跑、且部分已现实锚定"的规则，与"尚未建模或只在配置里隐含"的缺口，一次性钉成单一事实源（single source of truth）。
> 现状依据：`frontend/environment.py`（gym 式 `Environment`，reset/step/observation/action）、`frontend/drone.py`、`frontend/task.py`、`frontend/data_source.py`、`config/simulation.json`。
> 本文是改造方案（架构与界面改造方案.md）P0/P1/P2 的**前置事实基础**：渲染与交互的"真实感"必须先有这里锚定的世界规则。

---

## 0. 一句话结论

世界逻辑**已部分确定，且比"很假"的观感要扎实**：核心参数用真实机型、需求用热点+高峰模型、时间基准隐含为 1 步=1 秒。但**没有一份书面规格**，且**真实性在 UI 里完全不可见**，同时**缺风/天气/三维地形等环境动力学**——这才是"假"的真正来源。

## 2. 实体（已确定，大部分现实锚定）

### 2.1 无人机（✅ 真实机型，这是"真"的最强证据）
来自 `heterogeneous.drone_types`，全部对标公开机型：

| 类型 | 参考机型 | 速度 m/s | 载重 kg | 电池 Wh | 基础能耗 Wh/m | 满载航程 km |
|---|---|---|---|---|---|---|
| light_express | 美团第四代配送无人机 | 20.0 | 2.4 | 380.0 | 0.032 | 10 |
| standard_cargo | 顺丰丰翼方舟 ARK40 | 14.0 | 10.0 | 1600.0 | 0.06 | 20 |
| heavy_cargo | 大疆 FlyCart 30 双电 | 20.0 | 30.0 | 3968.8 | 0.142 | 16 |

- 运动学：`update()` 每步沿航线航点直线运动 `speed × time_step` 米；到航点即 `consume_battery(distance)`。
- 电量：`consumption = distance × base × (1 + 载重比 × load_penalty)` —— **线性能耗，无悬停/巡航区分、无质量/阻力/空气密度**（见 §5 缺口）。
- 异源机型池默认 5/3/2 共 10 架，heterogeneous 开关开启。

### 2.2 机巢 / 换电站（✅ 现实合理）
- 5 个站，坐标取自真实区域；`swap_time_seconds=180`（3 分钟换电）。
- **泊位仲裁（创新点）**：有限泊位（berths=2）+ 动态优先级（battery/wait/urgency 三权重）排队，priority 策略默认。统计含泊位利用率、排队等待、最长等待。

### 2.3 任务 / 需求（✅ 模型现实，且是"不假"的关键）
来自 `task.py` `RealisticTaskGenerator` + `simulation.json.task_generation.realistic`：
- **热点聚类**：60% 概率在 2 个热点中心（医院/商圈，半径 80 m）附近生成取送货点（`generate_hotspot_position`）。
- **高峰/平峰到达**：peak 20 步/单、平峰 45 步/单，`peak_probability=0.7`，`cycle_length=1200` 形成潮汐。
- **重量分档**（对应真实物流品类）：
  - 1–2 kg（55%，外卖/小件，美团轻载）
  - 3–10 kg（35%，标准快递，顺丰 ARK40）
  - 11–25 kg（10%，重货/应急，大疆 FlyCart30）
- **分类**：urgent/emergency（急救药品）、bulk（大件食品）、normal。
- **SLA 截止**：`deadline = 生成时刻 + 随机(900~3600s)`，并含 `sla_reference_speed=14`、`sla_base_seconds=420`、`sla_per_kg_seconds=24` 的可解释基线。
- 单局 `total_tasks=60`，初始 `initial_task_count=12`。

### 2.4 禁飞区（✅ 真实语义）
- 圆型"医院应急通道"（半径 150 m）+ 多边形"管制空域 A"。
- 生效于 `is_path_clear / A* / 场景生成`；触发绕飞计数 `total_no_fly_detours`。

### 2.5 环境（⚠️ 仅静态几何，无动力学）
- 真实 OSM 建筑（含高度>20 m 的高楼列表）、路网、禁飞区已加载。
- **无风速、无天气状态、无昼夜/能见度**——见 §5。

## 3. 单步推进规则（已确定）

`Environment.step(actions)` 每调用一次：
1. 把 `actions = {drone_idx: [task_id,...]}` 分配为航线（支持同源追加 / 异源顺路接入"任务链"，最多 3 段、绕飞阈值 1500 m）。
2. `current_time += 1`（秒）。
3. 按需生成新任务（交互式控制台可暂停自动订单流）。
4. 各 `drone.update()`：沿航点移动、扣电、到点取/送货、低电预判改道换电。
5. 统计：本步位移→里程（区分空载/载货）、忙步数、耗电/充电量、任务完成（航点弹出判定）。
6. 返回 observation / reward / done / info。

奖励体系（`reward_*`、`overdue_*`、`priority_delay_*`）与 QMIX 专用 `qmix_reward` 均已配置，用于 MARL 训练与基线对比。

## 6. 给 UI 的"真实性呈现"清单（直接对应 E 项，改造方案 P2 落地）

要让观众相信"这是真模拟而非编造"，界面必须主动亮出：
1. **机型铭牌**：每架机 hover/列表显示"美团第四代 / 顺丰 ARK40 / 大疆 FlyCart30 + 速度/载重/航程"。
2. **需求来源面板**：热点地图（标出医院/商圈）、高峰平峰潮汐曲线、重量分档饼图——证明"单子不是乱撒的"。
3. **SLA 解释条**：每次派单显示"为什么是这架——能力匹配/载重/电量/时间窗 + 对照 SLA 基线"。
4. **实时物理读数**：真实速度 m/s、实时剩余航程 km（按当前电量与机型能耗反算）、风（若补 B 项）。
5. **参数溯源面板**：一键查看"本次仿真全部参数 + 每项来源（OSM / 机型公开规格 / 物流品类统计）"。
