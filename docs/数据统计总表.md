## C. 地图几何（L1）—— 仓内那份 .osm 的逐元素普查（本轮现算）

复算命令（本地解析，不联网）：
```bash
PYTHONIOENCODING=utf-8 ../.venv310/Scripts/python.exe -c "
import xml.etree.ElementTree as ET,collections
ways=bld=hgt=lvl=road=node_cnt=rel_cnt=0;hw=collections.Counter()
for _e,el in ET.iterparse('frontend/data/map/part_of_yangpu.osm',events=('end',)):
    if el.tag=='node': node_cnt+=1
    elif el.tag=='relation': rel_cnt+=1
    elif el.tag=='way':
        ways+=1;t={k.get('k'):k.get('v') for k in el.findall('tag')}
        if 'building' in t: bld+=1; hgt+= 1 if t.get('height') else 0; lvl+= 1 if t.get('building:levels') else 0
        if 'highway' in t: road+=1; hw[t['highway']]+=1
    el.clear()
print(node_cnt,ways,rel_cnt,bld,hgt,lvl,road,hw.most_common(6))"
```

| **两者都没有 ⇒ 走 fallback 高度** | **85.74%** |

| 道路类型 top6 | service 833 · footway 368 · primary 212 · residential 206 · tertiary 200 · secondary 97 |

## F. 统计后的三条判断（都指向上面的数，不是印象）

1. **能耗基线是可修的，且有 A 级锚点**：heavy_cargo 应从 0.142 → **0.248 Wh/m**（派生自官方 3968.8 Wh ÷ 16 km）。
   另两型缺电池容量公布 ⇒ 只能沿用"派生 + 标 derived"或等 CMU 数据。
2. **载重惩罚系数这一项其实站得住**：官方悬停数据反推 ×1.61，项目公式 ×1.75，同量级。
   ⇒ 之前我把三个 C 级参数一起打成"全都不可信"是过宽了，**该改的是 consumption_base，不是 load_penalty_factor**。
3. **天气层今天起可用**：1008 小时真数据在 `data/raw/`，≥12 m/s 只占 0.10% ⇒
   可以说"绝大多数工况在两款机型的抗风包线内"，这比原来完全没有风参数强，且不需要新增依赖（CSV 读取即可）。
