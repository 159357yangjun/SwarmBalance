# SwarmBalance 群智优衡 · 项目报告

## 项目介绍

- **什么技术栈**
  - 前端技术栈：Vue 3、Three.js、ECharts 5、HTML/CSS、REST API
  - 后端技术栈：Python 3.10、FastAPI、Uvicorn、NumPy、osmnx、OR-Tools、PyMARL (IQL / VDN / QMIX, PyTorch)、pygame
- **具体是干什么的**
  面向**城市应急与低空物流**场景的异构无人机集群三维协同调度仿真平台：通过"能力匹配 + 任务链优化 + 机巢资源动态调度"实现多无人机、多任务、多机巢条件下的联合优化，并用 Greedy、OR-Tools 等基线做统一口径的对比验证。

## 最终你(作者)的期望

| 核心效果 | 描述 |
|---|---|
| 真实城市的低空数字沙盘 | 在真实 OSM 建筑 / 路网 / 禁飞区上还原配送场景，订单、机队、机巢在同一张三维地图上协同运行 |
| 主推算法可对比、可复现 | 以 GA（排列编码 + 贪婪分割 + 局部搜索）为主推，Greedy / OR-Tools 为基线，PSO 与 MARL（IQL / VDN / QMIX）作扩展；统一指标口径、同种子可复现 |
| 可解释的调度决策 | 每次派单都能说清"为什么是这架机"（能力匹配 / 载重 / 电量 / 时间窗），支持回放与"换一架会怎样"的反事实查看 |
| 可干预的运营调度台 | 运行中插单、改优先级、制造故障、关闭机巢，观察算法滚动重调度 |
| 面向真实空域与实机的延伸（远期） | 逐步支持时变空域管制与天气等随机因素，并预留与真实无人机 / 机巢集群对接的调度内核 |
