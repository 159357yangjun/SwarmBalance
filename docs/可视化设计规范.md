# 可视化设计规范（从 pygame 3D 实现提炼，供 Web/Three.js 端复用）

> 本文档从已退役的 `map_drawer_3d.py`（pygame 软件投影实现）中提炼出**仍然有价值、
> 与渲染引擎无关**的可视化设计参数与映射规则，供 Three.js 精致化时复用。
> 软件投影算法本身（azimuth/elevation 公式、画家算法）已由 Three.js 相机 + z-buffer 取代，不再保留。

---

## 1. 默认视角参数

| 参数 | 值 | 说明 |
|---|---|---|
| azimuth（方位角） | 35° | 绕 Z 轴旋转 |
| elevation（俯仰角） | 55° | 越大越接近俯视 |
| zoom | 1.0 | 初始缩放 |
| height_scale | 6.0 | 建筑高度放大系数（让低矮建筑立体感更强） |
| drone_altitude | 45 m | 无人机巡航可视高度 |

> Three.js 初始相机可用相近的俯仰角，保持"斜 45° 俯瞰"的观感。

## 4. 建筑高度缺失的合成规则

OSM 大部分建筑没有 `height` / `building:levels` 标签，需要合成确定性的合理高度：

```python
area = float(geom.area)
h = min(45.0, max(4.0, math.sqrt(max(area, 1.0)) * 0.6))
```

即：高度 ∝ 占地面积的平方根，下界 4 米、上界 45 米。**确定性**（无随机），保证可复现。

## 5. 建筑高度 → 着色规则（越高越深）

```python
t = min(1.0, h / 50.0)          # 归一化到 [0,1]
base = 216
wall  = (216 - 40t, 216 - 30t, 216 - 15t)   # 墙体：越高越深
roof  = (wall + (26, 24, 18))               # 屋顶：比墙亮一档
```
