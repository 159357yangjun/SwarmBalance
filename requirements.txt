#
# 【重要 3】pip 版本建议 23.x
#   pip 26.2.x 在 Windows 上有 safe-delete bug（SHFileOperationW 失败 0x2），
#   安装过程会卡死甚至损坏 pip 自身。
#
# 完整安装命令见 README「环境安装」一节。
